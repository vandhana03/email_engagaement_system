# Automated Email Engagement System

## Features

- Automated email simulation
- Intelligent sender/receiver distribution
- Positive reply simulation
- Reputation tracking
- Analytics APIs
- Celery background tasks
- Redis scheduling
- Swagger API documentation

## Tech Stack

- Django
- Django REST Framework
- PostgreSQL (Neon)
- Celery
- Redis
- drf-spectacular

## Setup Instructions

### Clone Repository

git clone YOUR_GITHUB_URL

### Create Virtual Environment

python -m venv venv

### Activate

venv\Scripts\activate

### Install Requirements

pip install -r requirements.txt

### Run Migrations

python manage.py migrate

### Start Server

python manage.py runserver
